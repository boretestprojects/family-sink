## 0.1.2

First version prepared for the Home Assistant community. See the [release notes](docs/RELEASE_NOTES.md).

- Slightly soften the participant-colored glow beneath each card.

- Restore local Manrope typography and the original glass cards, header and timeline styling.

## 0.1.0

- Package the Family Sink dashboard as a Home Assistant sidebar panel with bundled JavaScript, CSS and fonts.
- Discover devices and entities from the official Oral-B integration. Record from independent brushes with the original 30-second pause and 20-second minimum.
- Add persistent household profiles, assignments, scoring settings, authenticated avatars and legacy history transfer.
- Retain the scoring rules, glass-style dashboard, timelines, progress, summaries and three display languages.
- Use the Home Assistant time zone for gameplay across all clients. Add access to older history beyond the original seven visible dates.

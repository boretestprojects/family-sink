First version prepared for the Home Assistant community. See the [release notes](docs/RELEASE_NOTES.md).

- Package the Family Sink dashboard as a Home Assistant sidebar panel with bundled JavaScript, CSS and fonts.

- Use the Home Assistant time zone for gameplay across all clients. Add access to older history beyond the original seven visible dates.

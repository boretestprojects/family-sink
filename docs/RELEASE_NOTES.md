# Family Sink 0.1.3

**Every brush counts.** Family Sink is a local-first family toothbrushing game for Home Assistant, developed by Padezhki Lab.

This is the first version prepared for the wider Home Assistant community. It grew out of a dashboard and automations we built for our own family and used to make toothbrushing a little more fun.

- Open Family Sink from the Home Assistant sidebar for live brushing, progress rings, streaks, daily timelines and the Wall of Fame.
- Give each participant a color, an avatar or their own picture. Replace a toothbrush assignment to keep the same profile and history.
- See Golden Cards, previous weekly and monthly champions, and the daily winner. Adjust scoring and time windows from the administrator settings.
- Use English, Bulgarian or Lithuanian. Import an old brushing log or download your current history.
- In 0.1.2, the larger live badge pulses smoothly and the activity icon makes a two-second rotation. The colored glow beneath profile cards is softer.
- 0.1.3 prepares the community catalogue submission. It adds a My Home Assistant installation badge and declares the `http` dependency in the manifest. The integration, game rules and panel are unchanged from 0.1.2.

Family Sink requires Home Assistant **2026.10.0 or newer** and the official **Oral-B** integration. Install the ZIP manually, or add the public GitHub repository through HACS on 2026.10 or Marketplace on 2026.11 and newer. Catalogue inclusion is a separate step.
